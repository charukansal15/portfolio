The Relay

Evidence-first AI research paper Q&A

Python, asyncio, HTTPX, BM25, Groq API, GPT-OSS-20B

  1. AskA question about one of three research papers
  2. RetrieveA local BM25 index ranks the chunks
  3. Show evidenceRetrieved text streams to the user first
  4. DraftThe LLM answers from that evidence
  5. VerifyEach citation and claim is checked against it

77.8% accuracy on the 9 gradable answers, from a benchmark of 15 real questions.

  • Designed a retrieval-augmented QA system over three research papers. Papers are chunked and ranked with a local BM25 index, so every answer starts from retrieved source text instead of model memory.
  • Cut hallucination risk by streaming the retrieved evidence to the user first, then generating the answer and checking each citation and claim against that evidence before returning it.
  • Made the async Python service resilient to flaky LLM APIs with timeouts, bounded retries, fallback answers and per-request token budgets.
  • Built a deterministic mock LLM provider to reproduce rate limits, failures and concurrent load in tests, without API spend or flaky results.
  • Wrote up where the verifier failed and the system's limits.
